# CFLAG-Workspace

Repositorio coordinador de documentación para Codex.

Este repositorio no contiene el código productivo del frontend ni del backend.
Su función es mantener las reglas globales y la documentación transversal de CFLAG.

Repositorios relacionados:

- frontend
- backend

Antes de realizar cambios en cualquier repositorio, Codex debe leer `AGENTS.md`
y la documentación aplicable en `docs/`.
